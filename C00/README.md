# 💻 C00 - 42 Piscine

## 📖 Overview

C00 is the first C project of the 42 Piscine.

The objective is to learn the basics of the C programming language, understand how functions work, and write simple programs using the `write()` system call.

---

## 📚 Topics Covered

- C syntax
- Functions
- Variables
- Loops
- ASCII characters
- The `write()` function
- Basic algorithms
