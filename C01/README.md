## 📖 Overview

C01 introduces pointers, arrays, and memory manipulation in C.

The objective is to understand how data is stored in memory and how pointers can be used to access and modify values.

- Memory addresses
- Arrays
- Strings
- Swapping values
- Integer division and modulo
- Basic string manipulation
