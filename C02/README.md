# 💻 C02 - 42 Piscine

## 📖 Overview

C02 focuses on character handling and string manipulation.

The objective is to learn how strings work in C, manipulate characters, and reproduce some of the standard library string functions.

---

## 📚 Topics Covered

- Characters
- Strings
- ASCII table
- String copy
- Character checks
- String transformation
- Memory basics
