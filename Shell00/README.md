# 🐚 Shell00 - 42 Piscine

## 📖 Overview

Shell00 is the first project of the 42 Piscine.

The objective is to become familiar with the Unix/Linux environment and learn the basic shell commands used every day during the Piscine.

---

- File and directory navigation
- Creating and removing files
- File permissions
- Symbolic links
- Hard links
- Environment basics
- Command line usage
- Basic Git workflow
